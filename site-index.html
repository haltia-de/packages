Haltia packages

Signed Alpine packages of Haltia, a calm touch desktop. Alpine 3.24 and postmarketOS; armv7, aarch64, x86_64.

wget -O /etc/apk/keys/haltia-de-6ad4bb12.rsa.pub https://haltia-de.github.io/packages/haltia-de-6ad4bb12.rsa.pub
echo https://haltia-de.github.io/packages/alpine/v3.24 >> /etc/apk/repositories
apk update
apk add haltia-desktop          # the shell and the programs
apk add haltia-desktop-ru       # messenger, music, weather for Russian services

Спокойная сенсорная среда, которая о вас заботится. Исходники и issues — github.com/haltia-de.
